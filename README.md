# 🎓 Bilik Ustası

Azərbaycan məktəbliləri üçün fənlər üzrə bilik yoxlama oyunu. Fənn seç,
çətinlik səviyyəsini seç və vaxta qarşı xal topla!

## Fənlər

Riyaziyyat · Coğrafiya · Tarix · İngilis dili · Azərbaycan dili · Fizika · Kimya

Hər fənn üç çətinlik səviyyəsində təqdim olunur: **Asan** (5–6-cı sinif),
**Orta** (7–9-cu sinif), **Çətin** (10–11-ci sinif).

## Necə oynanılır

- Fənn və çətinlik səviyyəsi seç.
- Hər sual üçün 20 saniyə vaxtın var — nə qədər sürətli cavab versən,
  bir o qədər çox xal qazanırsan.
- Ardıcıl düzgün cavablar 🔥 seriya bonusu verir.
- Oyun sonunda nəticəni adınla reytinq lövhəsinə əlavə edə bilərsən
  (nəticələr brauzerdə lokal saxlanılır).

## Texnologiyalar

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)

## Quraşdırma

```bash
npm install
npm run dev
```
